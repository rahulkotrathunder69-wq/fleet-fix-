# Voltwise — Fleet EV Operations Demo

A responsive, customer-facing prototype for an electric-vehicle fleet maintenance and dispatch platform. Built as a single-file, no-build web app so it can be opened locally or hosted on GitHub Pages.

## Run it

Open `index.html` in a browser. No install or build step is required. The dashboard uses sample data and Google Fonts (internet connection recommended for the font).

## Demo features

- Fleet overview with utilization, battery-health and service KPIs
- Priority maintenance alerts and fleet health snapshot
- Searchable vehicle table with status filters
- New dispatch flow with technician, vehicle and work-order selection
- Responsive layout for desktop and mobile
- Toast feedback for prototype interactions

## Notes

This is a front-end demonstration with illustrative sample data. It does not connect to vehicle telematics, persist dispatches, send notifications, or provide predictive-maintenance recommendations. Those features need a backend and integrations before production use.
